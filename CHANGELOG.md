# Changelog

## 1.1.0

- Expanded adaptive retrieval architecture.
- Added deterministic embedding boundary and optional OpenAI embeddings.
- Added optional Qdrant vector retrieval.
- Added local entity graph retrieval for multi-hop flows.
- Added configurable web retrieval adapter.
- Added optional cross-encoder reranking.
- Added SQLite durable document storage with tenant metadata.
- Added API-key authentication and rate limiting.
- Hardened prompt-injection detection.
- Expanded ingestion and production container hardening.
- Expanded README architecture, flow, LLM and technology-stack documentation.
- Added security and storage regression tests.

## 1.0.0

- Initial adaptive RAG core with planning, hybrid retrieval, evaluation, citations, tracing and CI.
